# Keyboard Shortcuts (macOS)

## Window Management (Rectangle)
Base = ⌃ ⌥

| Action          | Shortcut       |
|-----------------|----------------|
| Left half       | ⌃ ⌥ ←          |
| Right half      | ⌃ ⌥ →          |
| Top half        | ⌃ ⌥ ↑          |
| Bottom half     | ⌃ ⌥ ↓          |
| Top-left        | ⌃ ⌥ U          |
| Top-right       | ⌃ ⌥ I          |
| Bottom-left     | ⌃ ⌥ J          |
| Bottom-right    | ⌃ ⌥ K          |
| Center          | ⌃ ⌥ C          |
| Maximize        | ⌃ ⌥ Return     |
| Restore         | ⌃ ⌥ Delete     |
| Resize bigger   | ⌃ ⌥ +          |
| Resize smaller  | ⌃ ⌥ -          |

## App / Window Switching (macOS)

| Action                     | Shortcut |
|----------------------------|----------|
| Switch apps                | ⌘ Tab    |
| Switch windows (same app)  | ^ Tab    |
| Mission Control            | ⌃ ↑      |
| Switch Spaces              | ⌃ ← / →  |

## Sublime Text

| Action                 | Shortcut     |
|------------------------|--------------|
| Switch files           | ⌃ Tab        |
| Add cursor below       | ⌘ ⌥ J        |
| Add cursor above       | ⌘ ⌥ K        |

## tmux

| Action                     | Shortcut   |
|----------------------------|------------|
| Reload tmux config         | ⌃ a r      |
| New window                 | ⌃ a c      |
| Next window                | ⌃ a n      |
| Previous window            | ⌃ a p      |
| List windows               | ⌃ a w      |
| Split pane horizontal      | ⌃ a -      |
| Close pane                 | ⌃ a x      |
| List sessions              | ⌃ a s      |
